Guia de instalação — passo a passo
1
Criar conta no Supabase
Acesse supabase.com, crie uma conta gratuita e clique em "New Project". Escolha um nome (ex: barberfinance), defina uma senha forte e selecione a região mais próxima (South America — São Paulo).
2
Criar as tabelas
No painel do projeto, vá em SQL Editor → New Query. Abra o arquivo 01_supabase_setup.sql que está junto com este sistema, cole todo o conteúdo e clique em Run. Isso cria todas as tabelas e já insere o plano de contas padrão.
3
Copiar as credenciais
Vá em Settings → API. Copie o Project URL e a anon public key. Cole nos campos acima e clique em Conectar.
4
Hospedar o sistema (opcional)
Para acessar de qualquer lugar, hospede este arquivo no Netlify (gratuito): acesse netlify.com → "Add new site" → "Deploy manually" → arraste a pasta com o arquivo HTML. Pronto, você terá uma URL pública.
